三不五时 SOMEWHILE

一家以导演与影像创作为核心、以 AIGC 和自研工具拓展制作方式的创意制作工作室。 团队把导演、摄影、美术、后期和研发放在同一个项目里，根据需求组合 AIGC、实拍、三维和代码动画， 从前期创意验证做到最终成片。

制作中反复遇到的问题，会沉淀成工具，帮助品牌持续生产内容。 创意选择、画面质量和最终交付由团队负责。

  • 前期创意与方向验证 — 参考、关键画面或短样片
  • 产品和角色控制 — 结构、材质、身份与连续性
  • 混合制作 — AIGC / 实拍 / 三维 / 代码动画
  • 声音与多版本交付 — 语言、市场与平台适配
  • 自研应用与制作管理 — 画布、工具与配额追踪

傅博 · 履历要点

导演、摄影指导。图片摄影作品包括《城殇》《桥》《间离式乡愁》《遗落的神明》。 拥有长达 8 年的摄影指导经验。

电影电视剧摄影作品：《我们的新生活》《最后一列绿皮火车》《追幸福的人》 （摄影指导）；《大侠卢小鱼》《谎言真探》（摄影指导）。

近年以 AIGC 与自研工具拓展商业影像制作，服务品牌、汽车、3C、软件模型与 IP 客户， 作品方向覆盖 AI 相关作品、商业广告与叙事短片。
